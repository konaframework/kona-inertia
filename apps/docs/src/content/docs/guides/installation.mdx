Inertia should feel like a one-liner. Prefer **`./grind install`** (or **`kona grind install`**), or the inertia starter kit. Manual Gradle edits are optional and listed at the end.

## Already have a Kona app?

From the app root (where `build.gradle.kts` / `build.gradle` lives):

```bash
./grind install inertia
# from anywhere under the app:
kona grind install inertia
```

That command:

1. Adds `org.konaframework:kona-inertia` to your Gradle dependencies.
2. Registers `InertiaServiceProvider` in `src/main/resources/META-INF/kona/providers` so grind/`PackageDiscovery` loads it on boot.

Then refresh Gradle and rebuild:

```bash
./gradlew build
# or just restart ./grind serve
```

Pin a version when you need to:

```bash
./grind install inertia --version=0.1.0
# or: kona grind install inertia --version=0.1.0
```

See the full package installer docs on Kona: [Installing packages](https://docs.konaframework.org/docs/packages/install/).

## Starting from zero

Scaffold an app that already includes Inertia wiring and a Vite client:

```bash
kona new my-app --kit=inertia
# Java sample path:
kona new my-app --kit=inertia --lang=java
cd my-app
./grind serve
```

## Finish wiring (existing apps)

`./grind install inertia` registers the provider. On an app that was **not** created with `--kit=inertia`, add the Inertia middleware after boot and point at a root view (or HTML shell):

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
app.boot()
app.resolve(HttpKernel::class.java).pushMiddleware(HandleInertiaRequests())
// e.g. config: inertia.root_view = "app"
```

</TabItem>
<TabItem label="Java">

```java
app.boot();
app.resolve(HttpKernel.class).pushMiddleware(new HandleInertiaRequests());
```

</TabItem>
</Tabs>

Kit-scaffolded apps already do this for you.

### Config keys

| Key | Purpose |
|-----|---------|
| `inertia.root_view` | Crema view name (e.g. `app`) |
| `inertia.root_html` | Plain HTML with `@page` / `@vite` when no Crema view |
| `inertia.version` | Asset version string |
| `inertia.public_path` | Directory for Vite `build/` and `hot` |

Details: [Configuration](../../essentials/configuration/) and [Vite](../../advanced/vite/).

## Going deeper — manual Gradle (optional)

Only if you are not using `./grind install` / the kit:

```kotlin
dependencies {
    implementation("org.konaframework:kona-http:0.1.0")
    implementation("org.konaframework:kona-crema:0.1.0")
    implementation("org.konaframework:kona-inertia:0.1.0")
}
```

Then register the provider yourself (or write `InertiaServiceProvider` into `META-INF/kona/providers`) and push `HandleInertiaRequests` as above.

Until Maven Central publishes are live for your version line, publish to Maven local from the Kona and kona-inertia checkouts (`./gradlew publishToMavenLocal`), or use SNAPSHOT coordinates that resolve from `mavenLocal()`. Generated apps resolve `org.konaframework` from **mavenLocal()** then Maven Central.
